## 性能与稳定性

- 1000 KnowledgeItems × 100 Wander Sessions：5 次呈现且 5 个 Wonder 全部唯一；其余重复上下文被历史冗余门静默。

- 多维 Patch 质心计算为当前最慢阶段；V0.1 不追求极限并发，未观察到重复爆炸或无界内存增长。

- 由早期动态 `0001` 产生 Runtime 表的已有数据卷，可由幂等 `0002` 无损接管并补齐索引。

- 重启 PostgreSQL 与 Backend 后，120 KnowledgeItems、1 Session、1 Wonder 保持完整。
- 备份/恢复脚本通过临时数据库回放验证，恢复后为 120 KnowledgeItems。
- 根目录多阶段镜像完成 React 与 FastAPI 统一构建；静态 UI、API、Alembic 启动迁移和可选 Basic Auth 冒烟通过。

## 发布边界

- 代码已推送到 `https://github.com/xxiaoxiong/WanderMind.git`，远端 GitHub Actions 通过；branch protection 与 `v0.1.0` tag/release 仍需仓库所有者完成。
- 人工价值判断不能由自动 proxy 代替；仓库所有者需使用 `data/human_evaluation_template.csv` 完成至少 10 次真实 Seed 验收。
- 免费托管数据库存在 30 天到期限制；长期个人数据必须使用持久数据库与定期备份。
- 因此本报告确认的是 **V0.1 engineering release candidate**，不替代人工产品验收和正式发布治理。
